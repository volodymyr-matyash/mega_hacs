

# MegaD HomeAssistant integration
[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/hacs/integration)
[![Donate](https://img.shields.io/badge/donate-Yandex-red.svg)](https://yoomoney.ru/to/410013955329136)

> Этот fork поддерживает Home Assistant 2026.8+. Домен интеграции `mega`,
> версия Config Entry и существующие `unique_id` сохранены, поэтому удалять и
> заново настраивать интеграцию не нужно.

Для установки добавьте
`https://github.com/volodymyr-matyash/mega_hacs` в HACS как пользовательский
репозиторий типа **Integration**, скачайте MegaD и перезапустите Home Assistant.
Перед заменой файлов сделайте резервную копию Home Assistant; саму запись MegaD
в разделе «Устройства и службы» не удаляйте.

Интеграция с [MegaD-2561, MegaD-328](https://www.ab-log.ru/smart-house/ethernet/megad-2561)

Если вам понравилась интеграция, не забудьте поставить звезду на гитхабе - вам не сложно, а мне приятно ) А если
интеграция очень понравилась - еще приятнее, если вы воспользуетесь кнопкой доната )

[Подробная документация](https://andvikt.github.io/mega_hacs/)
